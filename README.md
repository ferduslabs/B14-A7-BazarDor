# বাজার দর (Bazar Dor)

বাংলাদেশের বাজার দর ট্র্যাকার — প্রতিদিনের পণ্যের দাম এক নজরে।

## বিবরণ

বাজার দর একটি Next.js 14 অ্যাপ যেখানে আপনি বাংলাদেশের বিভিন্ন বাজারের পণ্যের দাম দেখতে পারবেন। চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ, মসলা — সব পণ্যের আজকের দাম এখানে।

## বৈশিষ্ট্য

- ৮টি ক্যাটাগরিতে ৩৭+ পণ্য
- বাজারভিত্তিক দামের তুলনা
- দামের ইতিহাস (গতকাল, গত সপ্তাহ, গত মাস)
- ব্যবহারকারী অ্যাকাউন্ট সিস্টেম
- পূর্ণরূপে মোবাইল রেসপন্সিভ
- বাংলা ভাষায় সম্পূর্ণ ইউজার ইন্টারফেস
- ডার্ক থিম সাপোর্ট (আসছে)

## প্রয়োজনীয় টেকনোলজি

- Next.js 14 (App Router)
- React 18
- Tailwind CSS
- DaisyUI
- React Hot Toast
- Context-based Authentication

## ইনস্টলেশন

```bash
npm install
```

## ডেভেলপমেন্ট

```bash
npm run dev
```

ব্রাউজারে [http://localhost:3000](http://localhost:3000) খুলুন।

## প্রোডাকশন বিল্ড

```bash
npm run build
npm start
```

## প্রজেক্ট স্ট্রাকচার

```
bazardor/
├── app/
│   ├── layout.js          # রুট লেআউট

│   ├── globals.css        # গ্লোবাল স্টাইল
│   ├── not-found.js       # 404 পেজ
│   ├── category/
│   │   └── [slug]/
│   │       └── page.js    # ক্যাটাগরি পেজ
│   ├── product/

│   ├── signin/
│   │   └── page.js        # সাইন ইন পেজ
│   ├── signup/
│   │   └── page.js        # সাইন আপ পেজ
│   ├── profile/
│   │   └── page.js        # প্রোফাইল পেজ
│   └── update-profile/
│       └── page.js        # প্রোফাইল এডিট পেজ
├── components/
│   ├── Navbar.js          # নেভবার
│   ├── Footer.js          # ফুটার
│   ├── Hero.js            # হিরো সেকশন
│   ├── ProductCard.js     # পণ্যের কার্ড
│   ├── PriceTicker.js     # দামের টিকার
│   ├── SkeletonCard.js    # লোডিং স্কেলটন
│   └── AuthGuard.js       # প্রোটেক্টেড রাউট গার্ড
├── lib/
│   ├── bangla.js          # বাংলা ডিজিট কনভার্টার
│   ├── fallback-data.js   # ফলব্যাক ডেটা
│   ├── fetchData.js       # API ফেচ (3-টায়ার ফলব্যাক)
│   ├── api.js             # ক্লায়েন্ট সাইড হুকস
│   └── auth-context.js    # অথেনটিকেশন কনটেক্সট
├── auth.js                # অথ কনফিগ
├── next.config.mjs
├── tailwind.config.js
└── postcss.config.js
```

## API ডেটা

প্রধান API: `https://api.api-store.workers.dev/api/bazardor`

ডেটা লোড করার সিস্টেম:
1. প্রধান API থেকে ডেটা আনার চেষ্টা
2. ব্যর্থ হলে বিকল্প API
3. তারপরও ব্যর্থ হলে লোকাল ফলব্যাক ডেটা
